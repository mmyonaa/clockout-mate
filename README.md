# 퇴근 메이트 🐱

작업 표시줄(Windows)이나 Dock(macOS) 위에 서서 퇴근까지 남은 시간을 말풍선으로 알려주는 데스크톱 펫입니다. 캐릭터·크기·퇴근 시각·응원 문구는 설정 창에서 바꿉니다.

## 실행

Node.js가 필요합니다. 첫 실행 때 Electron 바이너리(약 100MB)를 내려받습니다.

```bash
cd clockout-mate
npm install
npm start
```

## 설치 파일 만들기

```bash
npm run dist
```

macOS에서 실행하면 `dist/clockout-mate-<버전>-arm64.dmg`가 만들어집니다. 열어서 `ClockoutMate.app`을 응용 프로그램 폴더로 끌어다 놓으면 설치됩니다. 설치한 앱은 설정 창에서 "로그인할 때 자동으로 실행"을 켤 수 있습니다.

- **서명**: Apple 개발자 인증서 없이 임시(ad-hoc) 서명을 씁니다. 이렇게 만든 앱은 빌드한 그 Mac에서만 실행됩니다. 다른 Mac에 나눠 주려면 Apple 개발자 계정으로 서명·공증해야 합니다.
- **제품명은 영문**: `package.json`의 `productName`을 한글로 주면 빌드된 앱이 시작 직후 종료됩니다. 그래서 앱 파일 이름은 `ClockoutMate`이고, 화면에 보이는 이름(창 제목·트레이)만 한글입니다.
- **Windows**: `npx electron-builder --win`으로 설치 파일(NSIS)을 만들도록 설정돼 있습니다. Windows에서 빌드해야 합니다. Apple Silicon Mac에서는 앱 폴더까지는 만들어지지만 설치 파일로 묶는 도구가 인텔용이라 Rosetta 없이는 실패합니다.
- **아이콘**: `npm run icon`이 기본 캐릭터 그림에서 `build/icon.png`와 `build/icon.icns`를 다시 만듭니다.

## 사용법

| 동작 | 결과 |
|---|---|
| 캐릭터 클릭 | 폴짝 뛰며 응원 한마디 |
| 캐릭터 좌우 드래그 | 바 위에서 자리 이동 (위치는 저장됨) |
| 캐릭터 우클릭 또는 트레이 아이콘 | 설정… · 위치 초기화 · 종료 |

캐릭터 바깥은 클릭이 그대로 통과하므로 뒤에 있는 창을 평소처럼 쓸 수 있습니다.

## 설정

트레이 아이콘이나 캐릭터 우클릭 메뉴의 "설정…"으로 창을 엽니다. 값을 바꾸면 바로 반영되고 저장됩니다.

| 항목 | 내용 |
|---|---|
| 캐릭터 | 하치와레 · 치이카와 · 우사기 · 쿠리만쥬 · 랏코 · 풍뎅이 중 선택 |
| 퇴근 시각 | 분 단위로 입력 |
| 업무 시간에만 보이기 | 켜면 출근 시각부터 퇴근 시각까지만 캐릭터가 보이고, 그 밖에는 숨습니다. 트레이 아이콘은 남습니다 |
| 출근 시각 | "업무 시간에만 보이기"를 켰을 때만 나타납니다. 퇴근 시각보다 늦게 주면 자정을 넘기는 근무로 봅니다 |
| 크기 | 60%~200%. 캐릭터와 말풍선이 함께 커집니다 |
| 응원 문구 | 캐릭터를 클릭했을 때 나오는 말. 한 줄에 하나, 한 줄 14자까지, 최대 20줄. 비우면 기본 문구 |
| 로그인할 때 자동으로 실행 | 설치한 앱에서만 켤 수 있습니다 |
| 위치 초기화 | 캐릭터를 기본 자리로 되돌립니다 |

설정은 아래 파일에 저장됩니다.

- macOS: `~/Library/Application Support/ClockoutMate/config.json`
- Windows: `%APPDATA%\ClockoutMate\config.json`

## 상태별 모습

| 상태 | 조건 | 모습 |
|---|---|---|
| 평소 | 퇴근 10분 초과 전 | 눈을 깜빡이며 "퇴근 42분 전" |
| 임박 | 퇴근 10분 이내 | 입을 벌린 채 통통 튀고 말풍선이 노란색 |
| 퇴근 | 퇴근 시각부터 10분간 | 평소 얼굴로 더 빨리 튀고 "퇴근 시간이에요!" |
| 야근 | 그 이후 자정까지 | 평소 얼굴로 천천히 숨쉬며 "야근 1시간 15분째…" |

모든 캐릭터에는 남은 시간과 상관없이 잠깐씩 하는 짓이 있습니다(하치와레와 우사기는 둘을 번갈아 합니다). 평소·임박·퇴근·야근 어느 상태에서나 나오고, 이때 말풍선과 몸 움직임은 그 상태 그대로입니다.

| 캐릭터 | 하는 짓 | 간격 |
|---|---|---|
| 하치와레 | 눈웃음을 지으며 입을 벌려 웃음 ↔ 팔을 늘어뜨리고 눈물 한 방울을 단 채 울먹임 (번갈아) | 웃음 2초 → 쉼 4초 → 울먹 3초 → 쉼 4초 |
| 치이카와 | 고개를 살짝 기울이며 웃음 | 6초마다 2초 |
| 우사기 | 팔짱을 낌 ↔ 뒤돌아서서 꼬리를 보임 (번갈아) | 팔짱 3초 → 쉼 4초 → 뒷모습 3초 → 쉼 4초 |
| 쿠리만쥬 | 캔을 들고 입을 크게 벌린 "캬아" 얼굴 | 8초마다 3초 |
| 랏코 | 팔짱을 낌 | 8초마다 3초 |
| 풍뎅이 | 가부좌로 앉아 두 팔로 알통을 세운 "장수풍뎅이 왕" | 9초마다 3초 |

웃는 얼굴은 하치와레와 치이카와의 이 순간에만 나오고, 퇴근 시각에는 어느 캐릭터도 웃지 않습니다. 야근 중이라고 우는 표정이 되지도 않습니다 — 하치와레의 울먹이는 얼굴도 남은 시간과 상관없이 제 차례에 나옵니다.

## 구조

```
main.js              창 생성 · 위치 계산 · 트레이 · 설정 검증과 저장
preload.js           렌더러에 노출하는 IPC 다리
renderer/
  characters.js      캐릭터 그림(SVG) 정의. 펫 창과 설정 창이 함께 씀
  character.css      캐릭터의 색 · 선 · 표정 전환
  index.html         펫 창
  styles.css         펫 창의 배치 · 말풍선 · 몸 움직임
  pet.js             카운트다운 · 클릭/드래그 처리
  settings.html      설정 창
  settings.css
  settings.js
scripts/make-icon.js 앱 아이콘 생성
build/               앱 아이콘 (icon.png · icon.icns)
character/           캐릭터를 그릴 때 참고한 원본 그림, 캐릭터별 폴더 (앱은 읽지 않음)
```

## 동작 원리

작업 표시줄을 건드리지 않습니다. 투명하고 테두리 없는 항상-위 창 하나를 바 바로 위 좌표에 붙여 둔 것입니다.

- **위치**: OS가 알려주는 작업 영역(화면에서 작업 표시줄/Dock을 뺀 영역)의 바닥에 창 바닥을 맞추고, 발끝이 바에 걸치도록 3px(크기 100% 기준) 더 내립니다. 해상도나 바 크기가 바뀌면 다시 계산합니다.
- **클릭 통과**: 창은 기본적으로 마우스를 무시하되 이동 이벤트만 전달받습니다(`setIgnoreMouseEvents(true, { forward: true })`). 포인터가 캐릭터에 올라오면 무시를 풀고, 벗어나면 다시 겁니다.
- **드래그**: 드래그 중에는 메인 프로세스가 실제 커서 좌표를 직접 읽어 창을 옮깁니다. 창이 움직이는 동안에는 렌더러가 받는 좌표가 흔들리기 때문입니다.
- **크기**: 설정한 배율만큼 창 크기를 키우고, 창 안의 내용은 CSS `zoom`으로 같은 배율을 겁니다.
- **설정**: 설정 창이 바꾼 값을 메인 프로세스가 같은 규칙으로 걸러서(형식·범위) 저장하고 펫 창에 다시 보냅니다. 설정 파일을 직접 고쳐도 같은 규칙을 거칩니다.
- **캐릭터**: 만화 《치이카와》의 캐릭터 여섯을 참고해 인라인 SVG로 직접 그린 팬아트입니다. 모든 캐릭터가 몸 윤곽을 함께 쓰고 머리 윗선(귀·뿔)·색·무늬·얼굴만 다릅니다. 몸 비율은 `character/하치/하치_5.webp`(정면으로 서 있는 그림)를 재서 맞췄고, 하치와레의 웃는 얼굴도 같은 그림에서 쟀습니다. 하치와레의 울먹이는 얼굴은 `character/하치/하치_울먹_1.png`를 재서 맞췄습니다. 치이카와의 웃는 얼굴은 `character/치이/치이_3.jpeg`를 재서 맞췄고, 우사기의 팔짱은 `character/우사기/우사기_3.jpeg`를 참고했고, 뒷모습은 `character/우사기/우사기_뒤_1.jpeg`를 재서 맞췄습니다. 쿠리만쥬의 "캬아" 얼굴은 `character/쿠리/쿠리_캬아_2.jpg`를 참고했습니다. 표정은 상태마다 눈과 입을 갈아 끼웁니다. 랏코의 칼은 그리지 않았습니다. 트레이 아이콘은 캐릭터와 상관없이 고양이 실루엣이고, 실행 시 픽셀로 그립니다.

## 캐릭터 추가하기

`renderer/characters.js`의 `window.CHARACTERS`에 항목을 하나 더하면 설정 창에 자동으로 나타납니다. 몸 윤곽(`BODY`)·발(`feet()`)·얼굴(`face()`)은 공용 조각을 그대로 쓰고, 머리 윗선과 얼굴 수치만 새로 정하면 됩니다. 몸 색 같은 캐릭터 전용 스타일은 `character.css`에 `.char-<id>`로 겁니다. 잠깐씩 하는 짓을 주려면 항목에 `acts: [{ name, every, for }]`를 넣고, 그 이름이 걸렸을 때(`[data-act='<name>']`) 바뀔 모습을 `character.css`에 적습니다. 짓을 여럿 넣으면 각자 `every`초짜리 구간을 차례로 차지하며 번갈아 나옵니다.

## 알려진 한계

- macOS에서만 실행해 확인했습니다. Windows 동작은 확인하지 않았습니다.
- 주 모니터에만 나타납니다.
- 요일을 구분하지 않습니다. "업무 시간에만 보이기"를 켜도 주말에 같은 시간대면 나타납니다.
- "업무 시간에만 보이기"를 켜면 퇴근 시각에 바로 숨으므로 "퇴근 시간이에요!"와 야근 말풍선은 보이지 않습니다.
- 바를 자동 숨김으로 쓰면 작업 영역이 화면 전체가 되어 캐릭터가 화면 맨 아래에 섭니다.
- macOS Dock은 가로 범위를 알 수 있는 공개 API가 없어 높이만 맞춥니다. Dock이 없는 자리에서는 허공에 선 것처럼 보이므로 드래그로 Dock 위에 옮겨 둡니다.
- 캐릭터가 남의 저작물을 본뜬 팬아트라 개인 용도로만 씁니다. 앱을 공개 배포하려면 직접 만든 캐릭터로 바꿔야 합니다.
