# 퇴근 메이트 🐱

작업 표시줄(Windows)이나 Dock(macOS) 위에 앉아 퇴근까지 남은 시간을 말풍선으로 알려주는 데스크톱 펫입니다.

## 실행

Node.js가 필요합니다. 첫 실행 때 Electron 바이너리(약 100MB)를 내려받습니다.

```bash
cd clockout-mate
npm install
npm start
```

## 사용법

| 동작 | 결과 |
|---|---|
| 캐릭터 클릭 | 폴짝 뛰며 응원 한마디 |
| 캐릭터 좌우 드래그 | 바 위에서 자리 이동 (위치는 저장됨) |
| 캐릭터 우클릭 또는 트레이 아이콘 | 퇴근 시각 설정 · 위치 초기화 · 종료 |

캐릭터 바깥은 클릭이 그대로 통과하므로 뒤에 있는 창을 평소처럼 쓸 수 있습니다.

남은 시간에 따라 모습이 바뀝니다.

| 상태 | 조건 | 모습 |
|---|---|---|
| 평소 | 퇴근 10분 초과 전 | 눈을 깜빡이고 꼬리를 살랑이며 "퇴근 42분 전" |
| 임박 | 퇴근 10분 이내 | 입을 벌린 채 통통 튀며 꼬리를 빨리 흔들고 말풍선이 노란색 |
| 퇴근 | 퇴근 시각부터 10분간 | 눈웃음을 지으며 더 빨리 튀고 "퇴근 시간이에요!" |
| 야근 | 그 이후 자정까지 | 눈을 감고 눈물을 단 채 "야근 1시간 15분째…" |

퇴근 시각은 메뉴에서 16:00~20:00 사이 30분 단위로 고릅니다. 다른 시각이 필요하면 설정 파일의 `offTime`을 `"17:20"`처럼 직접 고친 뒤 다시 실행합니다.

- macOS: `~/Library/Application Support/clockout-mate/config.json`
- Windows: `%APPDATA%\clockout-mate\config.json`

## 구조

```
character/         캐릭터를 그릴 때 참고한 원본 그림, 캐릭터별 폴더 (앱은 읽지 않음)
main.js            창 생성 · 위치 계산 · 트레이 · 설정 저장
preload.js         렌더러에 노출하는 IPC 다리
renderer/
  index.html       캐릭터 SVG와 말풍선
  styles.css       상태별 모습과 애니메이션
  pet.js           카운트다운 · 클릭/드래그 처리
```

## 동작 원리

작업 표시줄을 건드리지 않습니다. 투명하고 테두리 없는 항상-위 창 하나를 바 바로 위 좌표에 붙여 둔 것입니다.

- **위치**: OS가 알려주는 작업 영역(화면에서 작업 표시줄/Dock을 뺀 영역)의 바닥에 창 바닥을 맞추고, 발끝이 바에 걸치도록 3px 더 내립니다. 해상도나 바 크기가 바뀌면 다시 계산합니다.
- **클릭 통과**: 창은 기본적으로 마우스를 무시하되 이동 이벤트만 전달받습니다(`setIgnoreMouseEvents(true, { forward: true })`). 포인터가 캐릭터에 올라오면 무시를 풀고, 벗어나면 다시 겁니다.
- **캐릭터**: 만화 《치이카와》의 하치와레를 참고해 인라인 SVG로 직접 그린 팬아트이고, CSS 애니메이션으로 움직입니다. 참고한 그림은 `character/하치/` 폴더에 있으며 앱은 이 파일들을 읽지 않습니다. 체형과 무늬, 눈·볼터치 위치는 정면으로 서 있는 그림(`하치_5.webp`)의 비율을 재서 맞췄고, 표정은 상태마다 눈과 입을 갈아 끼웁니다. 트레이 아이콘도 실행 시 픽셀로 그립니다.

## 알려진 한계

- macOS에서만 실행해 확인했습니다. Windows 동작은 확인하지 않았습니다.
- 주 모니터에만 나타납니다.
- 바를 자동 숨김으로 쓰면 작업 영역이 화면 전체가 되어 캐릭터가 화면 맨 아래에 앉습니다.
- macOS Dock은 가로 범위를 알 수 있는 공개 API가 없어 높이만 맞춥니다. Dock이 없는 자리에서는 허공에 앉은 것처럼 보이므로 드래그로 Dock 위에 옮겨 둡니다.
- 설치 파일(.dmg/.exe) 패키징과 로그인 시 자동 실행은 들어 있지 않습니다.
- 캐릭터가 남의 저작물을 본뜬 팬아트라 개인 용도로만 씁니다. 앱을 배포하려면 `renderer/index.html`의 SVG를 직접 만든 캐릭터로 바꿔야 합니다.
